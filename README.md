# ✈️ AI-Trip-Planner

An AI-powered travel planner that generates custom trip itineraries based on user preferences.

## 📌 Features
- 🗓️ **Custom Itineraries:** Generates day-by-day travel schedules.
- 💡 **AI Recommendations:** Suggests top places to visit, food spots, and activities.
- 🎯 **Personalized Experience:** Tailored according to budget, duration, and interests.

## 🛠️ Tech Stack
- **Language:** Python
- **AI/ML:** OpenAI API / Gemini API
- **Framework:** Streamlit / Flask
